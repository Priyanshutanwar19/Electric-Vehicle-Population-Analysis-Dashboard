# Electric-Vehicle-Population-Analysis-Dashboard
Electric Vehicle Population Dashboard (Excel Project)
📌 Project Overview
This project presents a comprehensive analysis and interactive dashboard based on the Electric Vehicle Population dataset from the Washington State Department of Licensing. The aim is to explore trends in EV adoption, identify key manufacturers and models, and provide meaningful insights through Excel-based data analysis and visualization techniques.

📂 Dataset Information
Source: data.wa.gov - Electric Vehicle Population

Region: Washington State, USA

Records: Each row represents a registered electric vehicle, including its make, model, year, location, and type (BEV or PHEV).

Fields Include:

VIN (Vehicle Identification Number)

Make & Model

Model Year

Electric Vehicle Type

County, City, ZIP Code

Clean Alternative Fuel Vehicle eligibility

🎯 Objectives
This project covers the following key objectives:

Top Manufacturers – Identify which EV manufacturers are leading in Washington.

Popular Models – Analyze the most common EV models on the road.

Geographical Distribution – Visualize EV spread across cities and counties.

Vehicle Type Breakdown – Compare Battery Electric Vehicles (BEVs) vs Plug-in Hybrids (PHEVs).

Year-wise Trend – Track the increase in EV adoption over different model years.

Interactive Dashboard – Create a user-friendly dashboard using Pivot Tables, Charts, Slicers, and Excel formulas.

⚙️ Excel Functionalities Used
Spreadsheet Functions: COUNTIF, SUMIF, VLOOKUP, TEXT, CONCAT, IFERROR, etc.

Pivot Tables & Charts: For aggregation and dynamic visualization.

Slicers and Timelines: For interactivity and filtering.

Conditional Formatting: For better readability and insights.

Data Cleaning: Filtering duplicates, handling nulls.

Chart Types: Bar, Line, Doughnut, Combo Charts.

Dashboard Navigation: Hyperlinks and structured layout for easy interaction.

📊 Final Output
An interactive Excel dashboard that allows stakeholders to:

Filter by manufacturer, model year, city, etc.

Visualize trends and regional distribution.

Gain quick insights into EV adoption patterns.

💡 Insights Gained
Tesla emerged as the dominant EV manufacturer.

Cities like Seattle and Bellevue show high EV density.

EV adoption shows a strong upward trend post-2018.

BEVs significantly outnumber PHEVs in recent years.
